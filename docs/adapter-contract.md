# 适配器约定 · 提案

当前实现消费离线事件，不执行下面的接入能力。

| 输入字段 | 当前解释 |
|---|---|
| `status` | `ok` / `timeout` / `error` / `invalid` |
| `payload` | `ok` 时要求非空对象，具体语义由未来任务验证器判定 |
| `reported_cost` | 非负数或 null；来源、币种和计费范围在运行记录中说明 |
| `max_attempts` | 包括回退在内的尝试上限；正整数 |

真实适配器接入前需要独立实现：请求 ID、超时及取消、可重试错误分类、幂等键、任务结果验证器、权限边界、费用来源和人工接管。先用离线失败事件说明预期行为，再接真实服务。

回放器中的尝试上限只约束事件消费次数，不能替代真实系统的时间、费用或并发硬限制。
